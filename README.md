QuickDict

一款为 Windows 打造的轻量级桌面词典。

QuickDict 致力于让查词更加简单、高效。它集成了快捷查词、在线翻译、单词发音、收藏管理与历史记录等功能，希望为日常英语学习提供一个方便、舒适的桌面工具。

这是我的第一个软件项目。我希望通过持续开发和改进，让 QuickDict 从一个个人作品逐步成长为真正实用的软件。

✨ 功能特色

* 🔎 快捷查词：通过快捷键等方式快速查询单词。
* 🌐 在线翻译：整合在线翻译服务，辅助理解词义。
* 🔊 单词发音：支持相关语音与文本转语音功能。
* ⭐ 收藏单词：保存常用词汇，方便日后复习。
* 🕘 历史记录：查看之前查询过的单词。
* 🌗 深色与浅色模式：提供不同的视觉主题。
* ⚙️ 设置系统：管理应用支持的个性化选项。
* 🖥️ Windows 桌面体验：专注于桌面环境下的日常使用。

🛠️ 技术栈

根据当前发布版本的程序信息：

* 开发框架：WPF
* 开发平台：.NET Framework 4.8
* 目标系统：Windows
* 目标架构：x64

📥 下载与安装
