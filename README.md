## ✨ 功能特色

| 功能 | 说明 |
| --- | --- |
| 🔎 **快捷查词** | 通过快捷键等方式快速查询单词 |
| 🌐 **在线翻译** | 整合在线翻译服务，辅助理解词义 |
| 🔊 **单词发音** | 支持相关语音与文本转语音功能 |
| ⭐ **收藏单词** | 保存常用词汇，方便日后复习 |
| 🕘 **历史记录** | 查看之前查询过的单词 |
| 🌗 **深色与浅色模式** | 根据使用习惯切换视觉主题 |
| ⚙️ **设置系统** | 管理应用支持的个性化选项 |
| 🖥️ **Windows 桌面体验** | 专注于桌面环境下的日常使用 |

## 📥 下载与安装

前往 **[GitHub Releases](../../releases)** 页面获取最新版本。

1. 打开 Releases 页面，下载最新版本的安装程序。
2. 运行安装程序，并按照安装向导完成安装。
3. 启动 QuickDict，开始使用。

> **安全提示**
>
> 如果 Windows 显示“未知发布者”或 SmartScreen 安全警告，请先确认安装包来自本项目可信的官方发布渠道，再决定是否运行。
